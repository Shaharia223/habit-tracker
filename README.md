# Habit Tracker 🎯

A lightweight, web-based personal habit tracking application designed to help you build consistency, visualize progress, and manage daily goals effectively.

---

## 🚀 Features

- **Daily Tracking:** Easily log completed daily habits and routines.
- **Progress Insights:** View your active streaks and completion history.
- **Clean Interface:** Minimalist design built for fast loading and mobile responsiveness.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Deployment:** GitHub Pages / Vercel
